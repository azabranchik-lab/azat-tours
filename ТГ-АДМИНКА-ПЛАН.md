# Telegram-админка для Alatoo — план

Управление контентом сайта через Telegram-бота: добавляешь туры/статьи и грузишь фото
прямо из мессенджера, бот обновляет данные сайта.

## Архитектура
- **Бот (Node.js, grammY)** слушает твои команды в Telegram
- Пишет в **JSON-хранилище** `content/tours.json` (+ фото в `images/tours/`)
- Пересобирает `tours-data.js` → сайт сразу показывает изменения (фронтенд не меняем)
- Авторизация по твоему Telegram ID — управлять можешь только ты

## Хостинг (важно)
Бот должен работать 24/7 → нужен Node-хостинг (Railway / Render free, или VPS),
а не статический Netlify. Один сервер: сайт + бот + фото.

## Команды бота (актуально)
/start /help · /tours /addtour · /posts /addpost · /leads /chats /reply · /cancel
Ответить клиенту в чат: просто Reply на сообщение «💬 Question…» в Telegram.

## Чтобы запустить бота (после получения токена)
1. Скопировать `config.example.json` → `config.json`
2. Вставить `token` (от @BotFather) и `ownerId` (твой Telegram ID от @userinfobot)
3. `node bot.js` → бот оживёт, пиши ему /start

## Что нужно от владельца
1. @BotFather → /newbot → прислать TOKEN
2. @userinfobot → прислать свой numeric Telegram ID (для авторизации)
3. Позже: выбрать хостинг (Railway/Render/VPS) для постоянной работы бота

## Команды бота (план)
- /start, /help — справка
- /tours — список туров (кнопки: открыть / удалить)
- /addtour — мастер добавления тура (название → категория → длительность → описание → фото → сохранить)
- /addpost — добавить статью блога (Фаза 3)
- /leads — последние заявки (Фаза 4)
