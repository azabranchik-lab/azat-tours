## Что сделано по пунктам брифа

### 1.1 Sitemap
- Уже генерировался из данных; убраны `changefreq` и `priority`, остались `loc` и `lastmod`.
- `lastmod` служебных страниц теперь из даты последнего коммита шаблона (`git log -1`), а не из mtime файла, который
  деплой сбрасывает. Туры и статьи как и раньше из `updatedAt`/`date`.
- Sitemap index пока не нужен (92 URL, один язык); появится вместе с `/ko/` в фазе 4–5. `llms.txt` генерируется из тех же данных.

### 1.2 Редиректы
- Все 257 известных старых адресов уже отдавали 301 за один хоп (фаза 0), менять нечего.
- **Решение по умолчанию:** неизвестный `tour.html?slug=` остаётся честным 404 (вы не ответили на вопрос из фазы 0,
  я оставил как есть). Если нужен 301 на `/tours/`, это одна строка в `server.js`.

### 1.3 «Sights visited»
- Причина: `places[]` сгенерированы скриптом из старых заголовков дней и не пересчитывались после переписывания маршрутов.
- Новый `scripts/check-sights.js` сверяет каждое место с текстом тура по написаниям газетира (`build-places.js`).
  Таблица: `seo-audit/sights-mismatch.csv`.
- Очевидные баги (место, которого нет ни в одном дне маршрута) убраны миграцией `2026-10-25-sights-fix`:
  `song-kul-horse-trek-3-days` → Issyk-Kul, `mai-tor-pastures-horse-trek-5-days` → Bokonbayevo (маршрут Epkin →
  Kereshke → Mai-Tor → Song-Kul, южный берег Иссык-Куля не задействован).
- **177 подсказок «место упомянуто в тексте, но не показано»** (например, Karakol, Fairy-Tale Canyon, Kochkor у
  длинных туров) я не применял: добавлять достопримечательности это решение о содержании. Список в CSV, удобнее
  разобрать вместе с хабами направлений в фазе 3.

### 1.4 Дубли на странице тура
- Один блок разметки вместо двух (мобильные вкладки + настольные секции): на телефоне вкладки Description /
  Additional info / What to pack / Before you go, на десктопе те же панели одна под другой с заголовками
  «Why you'll love this tour», «Good to know», «What to pack», «Before you go».
- Каждый текст встречается в HTML один раз: summary только в hero (и в JSON-LD), хайлайты один раз, список
  «включено» один раз. Факты pace/season/starts in остались в factbar и больше не повторяются во вкладке.
- «What to pack» и «Before you go»: 3–5 пунктов по типу поездки (winter 7 туров, horseback 36, trekking 7,
  road trip 13, day trips 16) плюс ссылка на `/blog/easy-from-abroad/`. Формулировки взяты из прежних списков.
- **Видимые изменения** (прошу глянуть): на десктопе появились «What to pack» и «Before you go» (раньше их видели
  только с телефона); во вкладке «Additional info» на телефоне вместо плиток факты списком, как на десктопе;
  во вкладке «Description» больше нет повторённого summary.
