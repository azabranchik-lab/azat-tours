# Тестирование сайта

## Автотесты (`npm test`, запускаются в CI перед каждым деплоем)

| Файл | Что проверяет |
|---|---|
| `tests/server.test.js` | Сервер на изолированной копии (без токена бота, свои `content/`): главные страницы 200, один H1, canonical; все старые адреса дают один 301 на живую страницу; неизвестные страницы настоящий 404 с навигацией; нельзя достать `config.json`, исходники, `.bak`, скрытые файлы, кривые URL дают 400; кэш (HTML `no-cache`, `?v=` и шрифты на год, картинки на неделю, ETag → 304); gzip; AVIF/WebP/JPEG по `Accept` и копии `?w=`; sitemap, robots, llms.txt, `.md` с noindex; API заявок (проверка email, ловушка для ботов, лимит размера и частоты, сохранение только нужных полей) и чата; полный `check-site` по всем URL и ссылкам |
| `tests/pages.test.js` | Содержимое: хайлайты и summary один раз, списки «What to pack» и «Before you go» по 3–5 пунктов, гайд по прибытию одной ссылкой, «Also available as» только на живые варианты, все места в «Sights» есть в маршруте, счётчики фильтров каталога = карточкам, ссылки главной на живые туры, title уникальны и ≤60, H1 = название тура |
| `tests/jsonld.test.js` | Разметка schema.org на всех типах страниц |
| `tests/migrate.test.js` | Миграции контента: исправляют что нужно, не трогают правки владельца в боте, делают снимок, второй запуск ничего не меняет, пустой контент останавливает деплой |
| `tests/related.test.js` | «Похожие туры»: ссылки распределяются по каталогу, без страниц с чужим canonical |
| `tests/reviews.test.js` | Отзывы показываются только когда есть, бейджи только по заданным ссылкам |
| `tests/backup.test.js` | Бэкап: состав архива, совместимость с системным tar, восстановление байт в байт, безопасные пути, расписание |
| `tests/images.test.js`, `tests/imgsize.test.js` | Фото из бота и копии нужной ширины |
| `tests/bot-cars.test.js` | Раздел машин в боте (мастер, публикация, правки, фото) |

Без локального `content/` (как в CI) тесты, которым нужен настоящий контент, пропускаются, остальные идут на
закоммиченных `public/*-data.js`.

## Ручная проверка перед крупной выкаткой
Делать на изолированной копии, тогда заявки и сообщения чата не уходят владельцу в Telegram:
```bash
node -e "require('./tests/helpers/site').startSite().then(s => { console.log(s.base); setInterval(() => {}, 1 << 30) })"
```
На 375 и 1280 px, в светлой и тёмной теме: главная (меню, тема, FAQ, форма), каталог (шторка и панель фильтров,
сортировка, `?cat=`), тур (вкладки, дни маршрута, FAQ, галерея и Esc, форма, WhatsApp), конструктор (все 4 шага,
подсказка без выбора, отправка), чат (отправка, просьба оставить email), блог и статья, About, Contact,
Plan your trip, 404. Признаки проблем: горизонтальная прокрутка, битые картинки, ошибки в консоли.

Особенность встроенного браузера Claude: он не прокручивает страницу к якорю `#…` при открытии (так же ведёт себя
и на чужих сайтах) и не проигрывает CSS-переходы. Это не ошибки сайта.

## Результат полной проверки 2026-10-25
- Автотесты: 57 из 57.
- Ручной прогон на 375 и 1280 px, обе темы: все пункты выше работают, ошибок в консоли нет, горизонтальной
  прокрутки нет ни на одной странице. Формы главной, тура, конструктора и чат отправлены на изолированной копии:
  заявки сохранились со всеми полями (в том числе сводка конструктора), подтверждения показаны.
