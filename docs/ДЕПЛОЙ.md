# Деплой Alatoo (сайт + Telegram-бот)

## Важно понять про этот проект
Это **не статический сайт**, а небольшое Node-приложение:
- `start.js` запускает **сайт + API (заявки/чат)** и **Telegram-бота** в одном процессе.
- Бот **пишет файлы на диск**: `content/*.json` (туры, статьи, заявки, чаты) и `images/tours`, `images/posts` (загруженные фото).

➡️ Поэтому нужен хостинг, который: (1) держит Node-процесс 24/7 и (2) имеет **постоянный диск** (чтобы загруженные фото и контент не стирались при перезапуске).

---

## Перед деплоем (обязательно)
1. **Пересоздай токен бота** (он светился в чате): @BotFather → `/revoke` → выбери бота → получи новый токен.
2. Токен и свой Telegram ID будем задавать **через переменные окружения** хостинга (не в коде):
   - `BOT_TOKEN` = новый токен
   - `OWNER_ID` = `913187557` (твой ID)
   - `PORT` = задаёт хостинг сам (код это учитывает)
3. `config.json` **не заливаем** в публичный репозиторий (он уже в `.gitignore`).

---

## Вариант A — VPS (рекомендую: дешевле и проще для этого приложения)
Цельный диск персистентный, фото бота не теряются. ~4–5 €/мес (Hetzner / DigitalOcean / Vultr).

Примерные шаги (дам точные команды, когда выберешь провайдера):
1. Создать сервер Ubuntu, зайти по SSH.
2. Установить Node 20+ и `pm2`.
3. Скопировать папку проекта на сервер, `npm install`.
4. Задать переменные окружения (`BOT_TOKEN`, `OWNER_ID`).
5. `pm2 start start.js --name alatoo` → работает 24/7, автозапуск после перезагрузки.
6. Поставить Nginx как reverse-proxy на порт + бесплатный SSL (Let's Encrypt).
7. Привязать домен (`alatoo.kg` / `.com`).

## Вариант B — Railway (управляемый, без сервера-администрирования)
Проще на старте, но нужен **Volume** для постоянного хранения фото/контента, и платный тариф (~$5/мес; бесплатный «засыпает» — для бота не годится).
1. Залить проект на GitHub.
2. Railway → New Project → Deploy from GitHub.
3. Start command: `node start.js`.
4. Variables: `BOT_TOKEN`, `OWNER_ID`.
5. Добавить **Volume**, примонтировать к папке данных (нужна небольшая правка путей — скажу какую).
6. Привязать домен.

> Render/Vercel/Netlify в чистом виде **не подходят**: Vercel/Netlify — статика без постоянного диска; Render free «засыпает».

## После деплоя
- Контент (туры/блог/фото/ответы в чате) редактируешь **сам через Telegram-бота**, вживую.
- Изменения дизайна/кода → правка файлов + повторный деплой (push в GitHub или копия на VPS).
- Проверь: открой сайт по домену, отправь тестовую заявку → пришла в Telegram; напиши в чат на сайте → пришло в Telegram, ответь Reply → появилось на сайте.

Когда выберешь вариант — дам пошаговые команды/настройки под него.
