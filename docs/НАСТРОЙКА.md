# Alatoo — инструкция для владельца сайта

Здесь по шагам: как включить форму заявок, как самому добавлять туры/блог через админку и как выложить сайт в интернет. Технических знаний не требуется.

---

## 1. Форма заявок — чтобы заявки приходили тебе на почту

Сейчас форма работает в **демо-режиме**: показывает «спасибо», но письмо не отправляет. Чтобы заявки реально приходили:

1. Зайди на **https://web3forms.com** → введи свой рабочий email (например, `info@твойдомен`) → получишь **Access Key** (длинный код).
2. Открой файл **`script.js`**, найди вверху строку:
   ```js
   const WEB3FORMS_KEY = "YOUR-ACCESS-KEY-HERE";
   ```
   и вставь свой ключ вместо `YOUR-ACCESS-KEY-HERE`. Сохрани.
3. Готово. Теперь каждая заявка с любой формы на сайте будет приходить тебе на email в течение секунды.

**Бесплатно:** до 250 заявок в месяц. Платить ничего не нужно для старта.

> 💡 Хочешь заявки ещё и в **Telegram**? Web3Forms умеет дублировать их в Telegram/Slack/Google Sheets — в их панели включается галочкой. Подскажу настройку, когда дойдём.

## 2. Как самому добавлять туры, фото и статьи (CMS / админка)

Ты выбрал вариант **«админка через браузер»** — заходишь на сайт, заполняешь поля, грузишь фото мышкой, жмёшь «Опубликовать». Чтобы это заработало, нужно:

1. **Выложить сайт в интернет** (см. пункт 3) — без этого админка работать не может.
2. Подключить **браузерную CMS** поверх текущего дизайна. Рекомендую **Decap CMS** (бесплатная, открытая): появляется адрес `твойсайт/admin`, где есть удобные формы «Добавить тур», «Добавить статью» с загрузкой фото. Дизайн сайта при этом **остаётся этот же**.

Это отдельный шаг настройки — сделаем его вместе после публикации. Тогда добавление нового тура будет выглядеть так: вошёл в админку → «Новый тур» → вписал название, цену, дни, загрузил фото → «Опубликовать» → тур появился на сайте.

---

## 3. Как выложить сайт в интернет (хостинг)

Сайт — это набор файлов в папке `kyrgyzstan-tours`. Самый простой бесплатный способ опубликовать:

1. Зарегистрируйся на **https://www.netlify.com** (бесплатно).
2. Перетащи папку `kyrgyzstan-tours` в окно Netlify → сайт за минуту окажется онлайн по адресу вида `имя.netlify.app`.
3. Позже подключаешь свой домен (например, `alatoo.kg`) — Netlify это умеет в пару кликов.

После публикации заработают: форма заявок, превью-картинки при репостах, и можно подключить CMS из пункта 2.

---

## 4. SEO — чтобы сайт находили в Google (после публикации)

В код уже встроено: уникальные заголовки, описания, разметка Schema.org (цена и рейтинг ★ в выдаче), карта сайта `sitemap.xml`, `robots.txt`, превью для соцсетей.

Что сделать руками после запуска:
1. Зарегистрируй сайт в **Google Search Console** (search.google.com/search-console) и загрузи туда `sitemap.xml`.
2. Создай карточку **Google Business Profile** (Google Карты) — для турфирмы это даёт много заявок.
3. Веди **блог** под запросы туристов («Ala-Kul trek», «Kyrgyzstan tours», «when to visit Kyrgyzstan») — это главный источник бесплатного трафика.
4. В файлах замени домен-заглушку `https://alatoo.travel` на свой реальный (в `sitemap.xml`, `robots.txt` и в тегах `og:` / `canonical` внутри страниц).

## Структура проекта

```
kyrgyzstan-tours/
├── index.html          ← главная страница
├── tours.html          ← каталог туров с фильтрами
├── tour-ala-kul.html   ← пример детальной страницы тура (с картой)
├── blog.html           ← блог
├── styles.css          ← все стили (один файл)
├── script.js           ← меню, фильтры, карта, ФОРМА (ключ Web3Forms здесь)
├── sitemap.xml         ← карта сайта для Google
├── robots.txt          ← правила для поисковиков
└── server.js           ← локальный сервер для предпросмотра
```
