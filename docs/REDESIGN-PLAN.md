  (V2), мелкие тап-миниатюры слайдов (V4).
- **Система = «Классик»:** кнопки-таблетки (радиус 999), чипы-таблетки, карточки 18-22px,
  золото точечно. Референсы: `hero-v1.png`, `sg-1..4.png`, `page-*.png`.
- **Внутренние страницы:** принцип «фото чистой лентой сверху (скруглённый низ), текст под ним»
  — каталог/тур/about утверждены по мокапам `page-tours/tour/about/contact.png`.
- **Каталог, фильтры:** логика НЕ меняется (чипы-категории лентой + кнопка со шторкой);
  кнопка переименовывается «Filters» → **«All filters»** для ясности.
- **Итинерарий тура:** структура СТАРАЯ один в один (удобнее в использовании) — только рескин
  цветов/шрифтов. Мокап с номерами-квадратами отменён.
- **Главное правило владельца:** внешность и расположение — можно; логику, флоу, набор
  элементов — нельзя без его «да» (полный текст в CLAUDE.md проекта).
